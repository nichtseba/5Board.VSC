# 5Board.VSC

5Board ist ein Tool, zum Erstellen, Bearbeiten und Halten von Präsentationen.
Es ist spezialisiert auf die Verwendung im Rahmen von Vorlesungen, die Inhalte zum Programmieren thematisieren. Quellcode kann in Codeblöcken, die mit Sourcedateien verknüpft sind, innerhalb der Präsentation ausgeführt werden.

## Funktionen
- Boards in VS Code erstellen und bearbeiten
- Projektoransicht in einem separaten Fenster
- Endlosscroll (keine einzelnen Folien)
- Codeblöcke erstellen und ausführen
- HTML-Export

# 5Board.VSC

5Board is a tool for creating, editing, and delivering presentations. It is designed for lectures covering programming topics. Source code linked to source files can be run directly from code blocks within a presentation.

## Features
- Create and edit boards in VS Code
- Projector view in a separate window
- Continuous scrolling, without individual slides
- Create and run code blocks
- Export to HTML
